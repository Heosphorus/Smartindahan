# Security Policy

## Security goals

smarTindahan aims to protect account access, store data, and operational records from unauthorized deletion, tampering, or disclosure.

## Security controls

- strong password validation and password hashing
- email verification before account access
- rate limiting on authentication attempts
- JWT-based access control
- role-based access restrictions for sensitive features
- audit logging for significant actions
- HTTP hardening headers and CORS restrictions

## Incident handling

Security issues are evaluated, contained, and investigated promptly. When an incident affects account integrity or exposure, the team documents the response and applies corrective measures to prevent recurrence.
