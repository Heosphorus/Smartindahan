# Audit Logging Policy

## Purpose

SariSmart maintains security and operational audit logs to support accountability and forensic review.

## Logged events

The system logs significant events including:

- account registration and email verification
- login attempts and failures
- password resets and changes
- logout activity
- security-related administrative actions

## Logging practices

Logs include timestamps, user identifiers, IP address, user agent metadata, and event details where appropriate. Access to logs is restricted to authorized personnel.
